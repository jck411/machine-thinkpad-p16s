# Spotify

Spotify uses the official Arch `spotify-launcher` package. Launch **Spotify (Launcher)**
from Rofi or run `spotify-launcher`; the dock layout uses the same launcher.
The launcher downloads and verifies Spotify's client from Spotify's repository
and manages it under `~/.local/share/spotify-launcher/`.

Account settings remain in `~/.config/spotify/`. Package declarations live in
`dotfiles_hyprland/packages/base.txt`.
